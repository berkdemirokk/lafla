# Lafla App Icon — Production Image Prompts

Three creative directions for the Lafla app icon, each delivered in three image-generation dialects: DALL-E 3, Midjourney v6, and Google Gemini Imagen 3. Paste prompts verbatim into the target tool. Do not mix dialects.

## Brand Constants (all directions)

- **Primary**: Hot pink `#FF067A` (vibrant magenta, near-fluorescent, NOT pastel)
- **Accent**: Electric cyan `#00FFFF` (pure aqua, high saturation)
- **Background**: Pure black `#000000` (no charcoal, no off-black)
- **Aesthetic**: Neon Noir — premium, adult, confident, NOT cute, NOT Duolingo green, NOT corporate blue
- **Output**: 1024x1024 square, flat 2D vector-style, suitable for iOS/Android icon mask
- **Negative space**: 8-10% safe padding from edges (icon mask will round corners at OS level — do not pre-round)

## How to Use

### DALL-E 3 (ChatGPT Plus / API)

1. Open ChatGPT with a Plus subscription, or hit the OpenAI Images API endpoint (`gpt-image-1` or DALL-E 3).
2. Paste the **DALL-E 3 prompt** verbatim. Do not edit. Do not preface with "make an icon of...".
3. For each direction, request **4 variants** by re-running the same prompt three additional times — DALL-E does not natively offer a "4 grid" UI inside ChatGPT, so manual re-runs are how you get a spread.
4. If a variant softens the colors (DALL-E sometimes desaturates hot pink toward salmon), follow up in the same chat with: *"Make the pink more saturated and electric — exact hex #FF067A, near-fluorescent magenta, not coral, not red."*
5. Download all four. Compare side-by-side at 60x60px (icon scale) — readability at small size is the kill criterion.

### Midjourney v6 (Discord or Web)

1. In the Midjourney Discord channel or web app, paste the **Midjourney v6 prompt** verbatim including the parameter flags. Do not strip `--ar 1:1 --style raw --v 6 --no ...`.
2. Midjourney returns a 2x2 grid of 4 variants automatically. Hit **V1-V4** to vary any seed, or **U1-U4** to upscale the keeper.
3. If the result feels too painterly or has unwanted gloss, append `--stylize 50` (lower the stylization). For maximum graphic flatness append `--stylize 0`.
4. To lock in a winning composition while varying execution, copy the seed and re-run with `--seed [number] --chaos 10`.
5. Upscale your winner with the standard upscaler (not the creative upscaler — it adds noise the icon doesn't need).

### Gemini Imagen 3 (Google AI Studio / Vertex AI)

1. Open Google AI Studio (aistudio.google.com) and select the Imagen 3 model, or call Vertex AI `imagen-3.0-generate-002`.
2. Paste the **Imagen 3 prompt** verbatim into the prompt field.
3. Set aspect ratio to `1:1` if exposed as a separate control, and request **4 samples** if the SDK exposes `sampleCount` (it does — default to 4).
4. Imagen 3 tends to render flat vector styles cleanly but occasionally introduces a soft outer glow. If that appears, follow up by appending: *"Absolutely no glow, halo, or bloom beyond the elements explicitly described."*
5. Download all four. Imagen 3 outputs at 1024x1024 by default — confirm in the metadata.

### Evaluation Checklist (apply to all 12 outputs across the three directions)

- [ ] Hot pink reads as `#FF067A` near-fluorescent, NOT coral or red or salmon
- [ ] Cyan reads as `#00FFFF` pure aqua, NOT teal or sky blue
- [ ] Background is pure `#000000` — no charcoal, no gradient, no noise
- [ ] No embedded text or letterforms beyond Direction A's L
- [ ] Canvas corners are square (icon mask handles rounding at OS level)
- [ ] Recognizable silhouette at 60x60px on a real device home screen
- [ ] No "AI generation tells" — no glass orbs, no melted edges, no extra fingers (yes, on icons too — Imagen has done this)
- [ ] Premium adult feel — would sit comfortably next to Things 3, Bear, Linear, Arc, NOT next to Duolingo or Babbel

### Iteration Strategy

Run all 9 prompts (3 directions x 3 tools) in one batch. Lay all 36 outputs (9 prompts x ~4 variants each) on a single Figma board at icon scale. Cull aggressively — keep the top 3 across all directions, then run those through the **Lafla brand-review checklist** (see `BRAND_GUIDELINES.md` if available) before committing to a final candidate. Direction A and Direction C will likely produce the cleanest outputs across all three tools; Direction B is the highest-variance bet because of the hidden L silhouette logic.
